existen formas de seleccionar y buscar una referencia de un nodo
podemos acceder a estos elementos mediante métodos que ofrece la API
id,etiqueta,clase,Colecciones de objetos HTML

Ejemplo básico
const element = document.getElementById("intro");

se busca la referencia del elemento con id "intro"
el nodo document me ofrece estos métodos

const parrafo = document.getElementsByTagName("p");

cambiando código HTML
la formá más fácil de cambiar contenido en HTML es mediante su propiedad innerHTML
el document nos ofrece una propiedad para estos elementos 
la sintaxis es obtengo desde el documento un elemento y lo modifico con nuevo contenido HTML 
el contenido por lo general suele ser string o texto o incluso utilizando template strings colocando nuevos elementos HTML

<p id="p1">Hello World!</p>

de este elemento cambiamos el contenido de su texto
document.getElementById("p1").innerHTML = "New text!";
